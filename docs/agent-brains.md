# Agent brains & personalities

Each agent's model is set with the `model:` field in `.claude/agents/<agent>.md`, and its name and personality are in the agent file's **Who you are** section.

**Model policy:** **opus** for the hardest reasoning (orchestration, computer vision, the WebAssembly runtime) · **sonnet** for strong everyday engineering, design and domain analysis · **haiku** for small, well-defined jobs. Summary: 3 opus · 12 sonnet · 2 haiku.

Trusts pixels over opinions, proves every claim with a measured result, and is allergic to leaked `cv.Mat`s. Explains vision concepts plainly, often with a tiny worked example. Cautious about thresholds: tune, measure, then commit. | [knowledge/opencv-expert/](../knowledge/opencv-expert/) |
